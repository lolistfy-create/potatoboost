PotatoBoost Mobile PWA\n\nPentru instalare ca aplicație PWA, fișierele trebuie publicate pe un hosting HTTPS (de exemplu GitHub Pages). Deschiderea index.html local permite testarea, dar instalarea PWA completă și service worker necesită HTTPS sau localhost.\n\nAplicația este un companion de setări și previzualizare. Nu poate modifica automat grafica altor jocuri, rezoluția Android sau FPS-ul.\n
